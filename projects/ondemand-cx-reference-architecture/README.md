# OnDemand CX — Reference Architecture & Enterprise Contact-Centre Platform

> Built the reference architecture and self-serve pricing tool behind an enterprise contact-centre platform, growing revenue from £500k to £16.6M in 18 months.

**Type:** case study
**Status:** live

## The Context / Challenge

Joined as Head of Cloud for an enterprise contact-centre software and services company, initially to support the CTO and represent infrastructure/cloud in front of customers alongside the solution architects designing the contact-centre platform. Solution design and scoping took around two weeks per customer, and nine solution architects were each building the same underlying software blueprint in nine different ways — creating inconsistency in pricing, scoping, and handover to the support team.

## The Solution / Process

Built a validated, tested reference architecture standardising the infrastructure and VM configuration across every design, cutting design time from two weeks to a few days. Layered an Excel-based elastic pricing tool on top of the reference architecture — sliders for user counts, front/back office mix, and application selection — letting solution architects and salespeople generate accurate, live pricing with a customer in minutes, independent of a solution architect, validated at 100% accuracy against final designs. Used the same reference architecture to consistently cost the company's existing SMB/mid-market solutions too.

Co-led the launch of an enterprise-grade contact-centre-as-a-service platform — the company's first move beyond SMB-focused infrastructure — which required auditing and upgrading enterprise-level security, networking and management across the stack, and negotiating a Dell OEM partnership that cut compute cost per server by roughly 50% while delivering 2-3x the compute density. Extended the architecture from private cloud to hybrid, adding AWS (first, for its stronger public cloud support at the time) then Azure as alternate deployment options, unlocking richer, IT-integrated propositions for customers.

## The Artifacts / Deliverables

- Validated, tested infrastructure reference architecture
- Elastic Excel-based pricing tool (slider-driven, self-serve)
- Enterprise security, networking and management uplift across the platform
- Dell OEM partnership
- Hybrid deployment architecture: private cloud + AWS + Azure

## The Outcome / Impact

- Solution design time: 2 weeks → a few days
- Customer pricing turnaround: 2 weeks → minutes, self-serve by sales
- 100% pricing accuracy validated against final designs
- ~50% compute cost reduction per server via Dell OEM partnership, 2-3x compute density
- Revenue growth: £500k → £16.6M in 18 months
- Opened a new enterprise route to market for the business
